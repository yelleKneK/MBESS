# Contributors to MBESS

MBESS has greatly benefited from the contributions, suggestions, and
corrections of many people over the years. I, Ken Kelley, gratefully
acknowledge the following contributors. Functions and components are
noted where applicable.

- **Bhargab Chattopadhyay**: helped with the minimum risk estimation
  functions, as part of a series of papers we coauthored.
- **Keke (Brian) Lai**: multiple functions; coauthor and maintainer for
  versions 3.0.0 through 3.3.3.
- **Mark Lachowicz**: helped with the `UpsES()` and `upsilon()`
  functions.
- **Kem Phillips**: contributed the original equivalence functions.
- **Kristopher (Kris) Preacher**: collaborator on a mediation analysis
  paper.
- **Sunthud Pornprasertmanit**: contributed functions as part of a
  paper we coauthored.
- **Joseph (Joe) Rausch**: early function discussion.
- **Leann J. Terry Diederich**: helped with some reliability functions
  as part of a joint paper we published.
- **Po-Ju Wu**: the `vit()` function.
- **Jan Hartman**: bug fixes.
- **Uri Simonsohn, Jeremy Biesanz, and Jochem König**: suggested
  handling the noncentrality parameter differently when it is zero.
- **Wing Ho Man**: documentation updates.
- **Samantha Anderson**: bug reports.
- **Guy Prochilo**: `ss.aipe.sm()` fixes.
- **Giulio Costantini**: reliability function corrections.
- **Keith Widaman**: dataset issues.

If you have contributed to MBESS and are not listed here, or if a
contribution is described incorrectly, please contact me at
kkelley@nd.edu so the record can be corrected.
